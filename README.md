# 🎯 Simple Click Game

A fun and simple browser game built using HTML, CSS, and JavaScript.

## 🎮 Game Description

In this game, the player has to click the moving box as many times as possible before the timer runs out. Each click increases the score, and the box changes position randomly.

## ✨ Features

- Click-based gameplay
- Score system
- Timer
- High score saving
- Random box colors
- Smooth animations
- Sound effects
- Mobile responsive design
- Start and Game Over screens

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Play

1. Click the **Start Game** button.
2. Click the box before time runs out.
3. Try to beat your high score.
